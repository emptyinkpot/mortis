## Mortis 是什么？

Mortis 是一个基于 Multica 收口而成的私人单用户智能体工作台。它保留了受管智能体、事项、项目、运行时与技能体系，但把外层品牌、入口与使用方式调整为更适合个人长期使用的私有部署形态。

当前这套实例的目标不是做公开 SaaS，而是作为个人控制台：

- 用一个固定身份直接进入工作区
- 统一管理事项、项目、智能体与运行时
- 把高频界面收口为中文可读表达
- 保持内部兼容名称稳定，避免不必要的高耦合迁移

## 当前文档重点

- 私有部署与域名切换
- 单用户自动进入模式
- 工作区、智能体、运行时与技能的日常使用
- 可见品牌层与内部标识层的迁移边界

## 技术底座

| 层级 | 当前技术栈 |
|-------|------------|
| 前端 | Next.js 16 (App Router) |
| 后端 | Go (Chi router, sqlc, gorilla/websocket) |
| 数据库 | PostgreSQL 17 with pgvector |
| 运行时 | 本地 / 远程 daemon 执行 Claude Code、Codex、OpenClaw、OpenCode、Hermes、Gemini 等 CLI |

## 使用建议

- 如果你只需要日常使用，直接进入 Mortis 主站即可
- 如果你要做运维或迁移，优先看部署说明与运行维护文档
- 如果你要继续深入改名，先单独设计“内部标识迁移方案”，不要直接硬改高耦合内部名
