## Differences

Mortis references OpenHands as an engineering-agent runtime precedent while keeping its own Multica-based runtime and operator shell.

Mortis is:

- private operator cockpit first
- artifact and approval oriented
- multi-channel command aware

Mortis is not:

- a standalone AI coding IDE
- a direct OpenHands fork
- a replacement for OpenHands runtime research

## Why OpenHands Matters

OpenHands matters because Mortis should treat AI code work like a controlled execution chain: task, workspace, terminal, file edits, tests, evidence, verification, and report. This is more important than adding more agents or personas.
